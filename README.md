# DevUtils-PS


Convert Commands
================
* devutils convert to-xlsx <input.csv> [output.xlsx]
* devutils convert to-csv  <input.xlsx> [output.csv]
* devutils convert to-json <input.csv|input.yaml|input.yml|input.xml> [output.json]
* devutils convert to-yaml <input.json|input.properties> [output.yaml]
* devutils convert to-xml <input.json> [output.xml]
* devutils convert to-properties <input.yaml|input.yml> [output.properties]
